FPGA Space Invaders

The final project for Digital Systems Laboratory: a 2D Space Invaders-style game running on an FPGA board. It draws to an HDMI display and reads input from a USB keyboard over SPI.

Tools

Overview

A game made of hardware

The game runs on FPGA fabric described in SystemVerilog. It renders to an HDMI display and takes keyboard input through an SPI-connected USB interface.
