RISC-V Operating System

The final project for my computer systems class: a Unix V6-inspired operating system for RISC-V, written in C. It boots, drives real (virtual) hardware, and runs multiple user-mode programs with memory protection.

When
Jan – Apr 2025
Type
Course final project
Language
C · RISC-V
Inspired by
Unix V6
What I built

A kernel, bottom to top

  • Device drivers for UART, the real-time clock and VirtIO block devices.
  • A read/write file system on top of the block driver.
  • Kernel threading.
  • Virtual memory with page-level protection between processes.
  • System calls and processes, so multiple user-mode programs can run side by side.
