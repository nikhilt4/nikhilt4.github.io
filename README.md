# nikhilt4.github.io

Personal site of Nikhil Talwalkar. Plain HTML/CSS/JS, no build step.

```
index.html          home page
projects/*.html     one page per project
assets/style.css    all styles (colour tokens at the top, light + dark)
assets/site.js      theme toggle, nav, scroll animation
assets/img/         images
```

Preview locally: `python3 -m http.server 8000`, then open http://localhost:8000

Search for `TODO` to find placeholders still to fill in.
